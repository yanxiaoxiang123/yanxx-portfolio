# Paper-unfolding artwork

Concept and keyframes were prepared using Oil Motion. The strict media budget selected baked-video with frame-scrub; see source/ and build/motion-budget.json.

## Current delivery

The user chose to ship the front-end scroll version after the configured MiniMax video account rejected generation (unsupported plan / insufficient applicable video quota). There is **no generated unfolding film** in this release. The home page uses the folded-paper artwork with native scroll-linked window expansion and scale; it does not simulate intermediate unfolding frames.

Start and intended end keyframes are retained. A true film can be integrated later with an eligible video provider, actual encoding metadata, a new strict budget, Pilot on-page verification and compiler-generated timeline. No keys belong in source or browser code.
