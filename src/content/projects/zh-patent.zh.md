## 背景

专利审查有一套细碎、经常变化的规则。如果每条规则都写在代码里，改一次就要重新发版，使用的人只能等。这个项目把规则从代码里拿出来，做成可配置的模板，并让本地大模型完成文档的结构化分析、合规审查与分类建议。

## 我做了什么

我独立完成了系统开发，也承担了部署、演示、培训和上线后的支持。

- 用多智能体规则引擎调用本地 Ollama 模型，以对话形式实时展示审核过程和结论。
- 把审核规则做成 JSON 配置，内置 4 套模板，规则调整不再依赖改代码和重新发版。
- 后端采用异步 FastAPI、MySQL 与 Redis 连接池；前端用 Vue 3，封装 API 拦截器和通用 Composables。
- 完成本地模型与环境部署、Nginx 统一代理，配置令牌认证、Redis 限流、会话吊销、服务故障转移和链路超时控制。
- 面向使用方演示系统、讲解审核流程和规则配置方式，主导操作培训并处理上线后的使用问题。

## 一个取舍

系统采用本地 Ollama 模型，并将审核规则保存在可配置模板中。模型输出作为辅助建议，规则配置、认证限流、超时控制与人工判断共同构成系统的使用边界。

## 结果

规则可以零代码调整，审核过程对使用者可见，系统在内网环境中完成部署并投入使用。我在这段经历里补上了前端、代理、认证限流和用户支持这几块，而不只是写后端。
